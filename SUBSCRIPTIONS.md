# 远程配置链接

公开 JSON 使用占位节点。请用[网页生成器](https://qixuancao.github.io/sing-box-config-templates/)或 CLI 加入自己的节点。

按客户端内核版本选择；[1.15 实验版](docs/experimental-1.15.md)位于同平台的 `1.15/` 目录。
