# Generator walkthrough / 生成器操作演示

- [GIF preview](generator-demo.gif) — 960 × 810, looping.
- [MP4 video](generator-demo.mp4) — 1280 × 1080, H.264, silent, approximately 6 seconds.
- Captured on 2026-11-05 from the [public generator](https://qixuancao.github.io/sing-box-config-templates/) in Firefox on macOS.

The walkthrough uses frame-by-frame captures of actual browser interactions, edited with readable holds and bilingual step captions. Browser chrome, bookmarks and the sidebar are cropped out. The native Firefox download panel is retained as an inset so its completion status is readable.

演示流程：粘贴节点分享链接 → 选择 macOS / SFM → 生成配置 → 下载 JSON。仅演示网页生成与下载，不包含客户端导入、授权或连接测试。

The fictional node uses `example.com` and `demo-password`; it is not a working proxy. No private subscription or real node credentials appear in these assets. The downloaded demonstration configuration passed `sing-box check` with sing-box 1.14.3.

To refresh the demo, repeat these steps with fictional credentials on the current public generator, capture the Firefox window, and update both media files together. Keep the steps aligned with the live UI and check that downloads complete before publishing.
