sing-box quick start: render locally, then import

These sing-box config templates cover Android SFA (1.13 / 1.14 core lines), iOS SFI, macOS SFM, Linux, and Windows, with FakeIP / RealIP DNS modes and TUN / mixed modes. Every platform provides sing-box 1.13 and 1.14 profiles.

Placeholder notice: every public Raw JSON file only contains example.com / CHANGE_ME. It passes sing-box check but cannot connect. Locate the file with the selector below, then inject your own outbounds locally with render.sh.

Configuration selector (runs locally in your browser)

Three steps: platform to core version to scenario. The selector never asks for or uploads subscription tokens, node addresses, or passwords.

Output

Render in three minutes

git clone https://github.com/qixuancao/sing-box-config-templates.git
cd sing-box-config-templates
cp examples/nodes.example.json nodes.json
# Edit nodes.json with your own standard sing-box outbounds
./scripts/render.sh platforms/android/1.14/fakeip.json nodes.json generated/android.json
sing-box check -c generated/android.json

nodes.json and generated/ are ignored by Git, and rendered files use mode 0600. See sing-box quick start in the repository.

FAQ

  • Can I import the public Raw JSON and connect directly?
    No. Placeholder nodes are only for preview, validation, and local rendering.
  • How do I choose 1.13 / 1.14?
    Use the core version shown by your client or sing-box version, then choose the matching platform directory.
  • FakeIP or RealIP?
    Start with FakeIP; switch to RealIP for incompatible apps.
  • Does the selector upload credentials?
    No. This page has no backend and no analytics script; everything runs locally.
