sing-box 配置快速入门：先本地生成，再导入

本仓库提供 sing-box 配置（sing-box config templates），覆盖 Android SFA（1.12 / 1.13 / 1.14 三条内核线）、iOS SFI、macOS SFM、Linux 与 Windows，含 FakeIP / RealIP 与 TUN / mixed。桌面与 Apple 配置面向 sing-box 1.14.x。

占位模板说明：所有公开 Raw JSON 都只含 example.com / CHANGE_ME，能通过 sing-box check，但不能直接联网。请先用下面的选择器定位文件，再用 render.sh 在本地注入你自己的出站。

配置选择器（纯浏览器本地运行）

三步定位：平台 → Android 内核版本 → 使用场景。选择器不要求、不上传订阅 Token、节点地址或密码。

输出

三分钟本地生成

git clone https://github.com/qixuancao/sing-box-config-templates.git
cd sing-box-config-templates
cp examples/nodes.example.json nodes.json
# 编辑 nodes.json，换成你自己的标准 sing-box 出站
./scripts/render.sh platforms/android/1.14/fakeip.json nodes.json generated/android.json
sing-box check -c generated/android.json

nodes.json 与 generated/ 已被 Git 忽略，生成文件权限为 0600。完整说明见仓库 sing-box 配置快速入门。

常见问题

  • 公开 Raw JSON 能直接导入联网吗？
    不能。占位节点只能用于预览、校验与二次生成。
  • Android 如何选择 1.12 / 1.13 / 1.14？
    以 SFA 关于页的内核版本为准；顶层链接跟随 1.14，旧内核用版本化目录。
  • FakeIP 与 RealIP 如何选择？
    日常先用 FakeIP；应用异常换同平台 RealIP。
  • 选择器会上传凭据吗？
    不会。本页无后端、无分析脚本，所有计算都在本地完成。
